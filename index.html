Must-know

  • Agent = Pac-Man. Environment = the maze. Reward = feedback (−0.04 per step, +1 for 🍒, −1 for a ghost).
  • Q(s, a) = how good action a is in state s. Arrows show the best action per tile.
  • Update: Q ← Q + α [ r + γ · max Q′ − Q ]
  • Exploration vs exploitation: with chance ε Pac-Man tries a random move. Set ε = 0 early and it may get stuck on a bad route.
  • γ near 1 = cares about long-term reward. γ near 0 = only cares about the next step.
